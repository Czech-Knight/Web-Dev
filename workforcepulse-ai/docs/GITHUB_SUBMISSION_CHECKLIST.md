# GitHub Submission Checklist

Use this before making the repository public or adding it to a resume.

## Required

- [ ] Project opens with `npm run dev`
- [ ] Frontend works at `http://localhost:5173`
- [ ] Backend health works at `http://localhost:4000/api/health`
- [ ] `npm run test` passes
- [ ] `npm run build` passes
- [ ] README has real screenshots added under `docs/screenshots/`
- [ ] GitHub repository description is clear and professional

## Recommended GitHub Repository Description

Full-stack AI workforce analytics dashboard with React, TypeScript, Node.js, Express, forecasting logic, skill gap analysis, REST APIs, and interactive scenario simulation.

## Recommended Repository Topics

```txt
react typescript nodejs express workforce-analytics forecasting dashboard data-visualization ai mlops labour-market fullstack
```

## Suggested Resume Bullet

Built WorkforcePulse AI, a full-stack workforce analytics platform using React, TypeScript, Node.js, Express, REST APIs, and Recharts to visualize simulated labour market trends, demand forecasts, skill gaps, and training scenario outcomes.
