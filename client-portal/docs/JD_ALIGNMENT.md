# Job Description Alignment

This project is designed in construction and infrastructure digital systems.

| JD Area | Project Evidence |
|---|---|
| Web Development | ASP.NET Core API, HTML/CSS/JavaScript frontend, role-based dashboard, admin panel |
| System Maintenance | Docker Compose, IIS deployment notes, AWS EC2 deployment notes, environment configuration |
| Database Integration | MongoDB collections for users, projects, tasks, documents, comments, and activity logs |
| UI/UX | Responsive dashboard, project cards, progress indicators, task chips, clear empty states |
| Bug Testing and Debugging | Test plan covering auth, permissions, documents, browser checks, and regression checks |
| Team Collaboration | Sprint-style workflow represented through tasks, comments, and activity tracking |
| Documentation and Reporting | API reference, deployment guide, test plan, README, and structured project setup |
| Construction Context | Project status, site location, safety summary, BIM package reference, client project documents |

The portal is intentionally client-facing rather than purely technical, so it reflects the type of real-client digital platform work.
